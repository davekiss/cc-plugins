# cc-plugins

This marketplace has moved to [davekiss/mods](https://github.com/davekiss/mods), which lists every plugin here plus leaks, burn and agentcam. Both are named `davekiss`, so remove this one before adding the new one:

```
/plugin marketplace remove davekiss
/plugin marketplace add davekiss/mods
```

Plugins you installed as `<name>@davekiss` keep the same names.
